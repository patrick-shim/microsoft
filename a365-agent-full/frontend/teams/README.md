# Teams app package

This folder holds the **Teams app package** for the AI Teammate — the `manifest.json`
plus two icons (`color.png` 192×192, `outline.png` 32×32) that `a365 publish` zips into
`manifest.zip` for upload to the Microsoft 365 Admin Center.

> **The CLI owns `manifest.json`.** `a365 setup all --aiteammate --m365` generates it
> (Teams v1.22+ schema with `bots[0].botId`, `webApplicationInfo.id`, and the
> `copilotAgents.customEngineAgents` AI-Teammate marker) and `a365 publish` re-substitutes
> the ids at package time from `backend/a365.generated.config.json`. **Do not hand-edit it** —
> re-run `a365 setup all --aiteammate` if a field looks wrong.

## Where the files come from

- `manifest.json` — generated by the CLI (Phase B, step "Register blueprint").
- `color.png` / `outline.png` — placeholder icons are generated by
  `deploy/generate-icons.ps1`; replace them with your real branding any time before publish.

## Flow (see the root README for full detail)

1. `a365 setup all --aiteammate --m365` → generates the manifest.
2. `a365 publish` → produces `manifest.zip`.
3. Upload `manifest.zip` at **M365 Admin Center → Agents → Upload custom agent**.
4. **Teams Developer Portal** → verify Agent Type = *API Based*, Notification URL = your
   `/api/messages` endpoint: `https://dev.teams.microsoft.com/tools/agent-blueprint/<blueprintId>/configuration`
